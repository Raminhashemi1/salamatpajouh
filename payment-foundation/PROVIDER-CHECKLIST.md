# فهرست کارهای قبل از فعال‌سازی پرداخت

## درگاه داخلی IRR
- [ ] قرارداد رسمی پذیرندگی، حساب تسویه و کسب‌وکار ثبت/تاییدشده
- [ ] مستندات درگاه تأیید کند واحد درخواست **ریال** است
- [ ] تعرفه سالانه ریالی به تایید مالک محصول برسد
- [ ] سرور وضعیت پرداخت و مبلغ را مستقیماً از درگاه Verify کند

## درگاه خارجی USD/EUR
- [ ] کشور قانونی شرکت/فروشنده، حساب تجاری و حساب تسویه مشخص باشد
- [ ] ارائه‌دهنده به‌صورت رسمی فعالیت و مشتریان مربوطه را بپذیرد
- [ ] محدودیت‌های کشور و تحریم‌ها با ارائه‌دهنده بررسی شود
- [ ] قیمت USD/EUR مستقلاً تصویب، مالیات و سیاست استرداد تعریف شود
- [ ] **تا این مرحله دکمه بین‌المللی غیرفعال بماند**

## مشترک
- [ ] ورود و حساب کاربری، پایگاه داده و سرور HTTPS
- [ ] secretها فقط سمت سرور؛ دسترسی مدیر محافظت‌شده
- [ ] idempotency، تایید server-to-server، ثبت اتمی و کنترل بازپخش
- [ ] آزمایش موفق، ناموفق، تکراری، رقم/ارز نادرست و callback جعلی
- [ ] حفاظت از داده شخصی و شرایط خرید/لغو/بازپرداخت
