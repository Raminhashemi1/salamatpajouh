# سلامت‌پژوه — مبانی پرداخت (نسخه توسعه، بدون دریافت وجه)

**این شاخه یک چارچوب فنی است؛ پرداخت واقعی فعال نیست.** سایت فعلی روی GitHub Pages ایستا است و نمی‌تواند مستقل از سرور امن تراکنش را تأیید کند.

## سیاست تاییدشده
- داخلی: **ریال ایران (IRR)**، مقدار صحیح بدون اعشار، با کارت بانکی ایران؛ تا هنگام اتصال پذیرنده غیرفعال.
- بین‌المللی: مسیر جداگانه USD/EUR با تعرفه مستقل؛ **غیرفعال** تا زمانی که پذیرنده قانونی، کشور/مشتریان مجاز و حساب تسویه تأیید شوند.
- خرید اول: یک سال اعتبار، ۱۰٪ تخفیف فقط برای عضو جامعه هدف با خوداظهاری اختیاری و بدون مدرک.
- تمدید بعد از انقضا: برای همه اعضا ۳۰٪ تخفیف. تخفیف‌ها تجمیعی نیستند؛ عضو فعال دوره جدید نمی‌خرد.
- تمام به‌روزرسانی منابع برای اعضای دارای اشتراک فعال رایگان است.

## فایل‌ها
- payment-core.mjs: محاسبه نرخ، تخفیف، انتخاب مسیر و تطبیق تراکنش بر مبنای داده معتبر سرور
- payment-core.test.mjs: ۱۷ تست خودکار
- schema.sql: الگوی دیتابیس سفارش و اشتراک، کلید یکتا/آیدیپوتنسی
- API-CONTRACT.md: قرارداد پیشنهادی درخواست سفارش و callback
- PROVIDER-CHECKLIST.md: اقدامات لازم قبل از پذیرش وجه
- checkout-preview.html: پیش‌نمایش رابط؛ دکمه‌های پرداخت غیرفعال

آزمایش با Node.js نسخه ۲۰ به بالا:

    node --test payment-core.test.mjs

**تعرفه نمونه قبلی سایت**: ۱٬۲۰۰٬۰۰۰ تومان = ۱۲٬۰۰۰٬۰۰۰ ریال. این تنها مثال تبدیلی است و قیمت مصوب فروش نیست. USD و EUR قیمت مصوب ندارند. هیچ پرداختی را با تبدیل نرخ بازار به‌صورت خودکار محاسبه نکنید.

## امنیت و کارهای باقی‌مانده
ساخت حساب کاربری و احراز هویت، سرور HTTPS و پایگاه داده، مدیریت کلیدها، محدودیت درخواست، کنترل مالکیت سفارش، تایید واقعی provider-to-server، ثبت اتمی سفارش/حق عضویت، گزارش مالی، مالیات و بازپرداخت باید قبل از فعال‌سازی پیاده شوند. کلید پذیرنده را هرگز در مخزن عمومی، HTML یا گفت‌وگو قرار ندهید. درخواست برگشتی مرورگر مدرک پرداخت نیست.

فعال‌سازی پذیرنده خارجی تنها پس از بررسی محدودیت‌های کشور/کسب‌وکار نزد خود ارائه‌دهنده مجاز است؛ هیچ مسیر دور زدن تحریم یا جعل محل فعالیت طراحی نشده است.
