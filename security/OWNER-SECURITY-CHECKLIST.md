# برنامهٔ اجرایی حفاظت از سلامت‌پژوه (قبل از استقرار)

- [ ] مالک GitHub ورود دومرحله‌ای را فعال کند و کدهای بازیابی را در مکان امن نگه دارد.
- [ ] مالک صفحهٔ GitHub → Settings → Branches/Rules را باز کند و حفاظت شاخهٔ main را تنظیم کند (PR، جلوگیری از حذف/force push، بررسی CI).
- [ ] مالک وضعیت collaboratorها، توکن‌ها، GitHub Apps و دسترسی‌های استقرار را بررسی کند؛ فقط دسترسی‌های ضروری بمانند.
- [ ] مشخص شود دامنه، DNS، هاست/Pages و نسخهٔ پشتیبان با حساب چه کسی مدیریت می‌شوند.
- [ ] تأمین سرویس احراز هویت و دیتابیس با دسترسی امن و کنترل نشست.
- [ ] دو نقش owner و content_editor در سرور ایجاد و سیاست دسترسی در تمام مسیرهای API اعمال شود.
- [ ] چرخهٔ ثبت پیش‌نویس، بررسی و انتشار نهایی توسط مالک با ثبت سابقه راه‌اندازی شود.
- [ ] تفکیک گزارش درآمد شریک از تنظیمات تسهیم/هزینه‌ها با کنترل سمت سرور.
- [ ] سناریوهای رد دسترسی، غیرفعال‌سازی شریک، حذف نشست، حساب مسدود، CSRF و XSS آزمایش شوند.
- [ ] بازبینی امنیتی و تست مستقل؛ تنها پس از تأیید، ادغام و استقرار.
