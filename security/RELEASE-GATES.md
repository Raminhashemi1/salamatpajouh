# Release gates — مالکیت و کنترل سلامت‌پژوه
**این سند و سیاست مجوزها هنوز به سایت اصلی متصل نشده‌اند؛ ادغام PR به‌تنهایی دسترسی را امن نمی‌کند.**

## پیش‌شرط‌های انتشار
- [ ] قراردادهای توسعه نرم‌افزار و اسناد حقوق مادی بازبینی شوند؛ مالکیت حساب GitHub به‌تنهایی اثبات حقوق معنوی/مادی نیست.
- [ ] احراز هویت و نشست سمت سرور، پایگاه داده و فرآیند ابطال نشست‌های فعال ساخته شوند.
- [ ] نقش `owner` تنها برای مالک تأییدشده و نقش `content_editor` تنها از پایگاه داده/نشست معتبر خوانده شود.
- [ ] تمام عملیات ایجاد/ویرایش/بررسی/انتشار محتوا، گزارش مالی، حساب‌های بانکی، و تنظیم نسبت درآمد در مسیرهای API کنترل دسترسی شوند.
- [ ] شریک فقط پیش‌نویس‌های خود را ببیند/ویرایش کند؛ انتشار محتوا نیازمند تایید مالک باشد.
- [ ] کنترل دسترسی با آزمون یکپارچه + درخواست مستقیم API (بدون اتکا به مخفی بودن دکمه‌ها) سنجیده شود.
- [ ] HTML منتشرشده برای XSS/تزریق محتوا بررسی شود؛ sanitization و سیاست محتوا اعمال شود.
- [ ] ورود دومرحله‌ای حساب GitHub، حفاظت شاخه `main`، اسکن رازها و پشتیبان‌ها بررسی شوند.
- [ ] حساب و دسترسی دامنه، DNS، انتشار سایت، هاست، دیتابیس و پذیرنده صرفاً تحت کنترل مالک باشند.
- [ ] محل ذخیره فایل، سیاست حفظ داده، امنیت پزشکی/محتوای علمی و مجوز نشر محتوا مشخص شود.
- [ ] تأیید و مستندسازی نهایی توسط مالک و ارزیابی مستقل امنیتی پیش از فعال‌سازی.
